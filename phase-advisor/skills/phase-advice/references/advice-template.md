# Advice format

Use this structure. Keep each section short.

**Issue and phase**
`KEY-123` — summary. Phase: *<phase>* (<how it was determined; ask the user to correct it if it was a guess>).

**What to watch for**
Up to five items, most relevant first. Each item:
- The risk or check, in one sentence.
- Evidence: `KEY-45` (matched on component: X) or the page title, or "generic phase check".
- What to do about it.

**Related history**
The similar issues you used, one line each, with key, status and why they matched. If none, write "No similar resolved issues found on this site."

**Related knowledge**
The Confluence pages you used, with title and space. If none, write "No matching pages found."

**Gaps**
What you could not determine (for example the phase was assumed, or components were missing so matching was weak), and what would improve the advice.
